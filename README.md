# 一凡工作台

> 一个纯前端、离线可用、能装进手机桌面的备考工作台（PWA）。
> 考研数学 · 考研英语 · 408 · 资产评估 · 国考行测 · 申论 · 创作复盘 · 课表管理，九个模块一个 App 搞定。

马卡龙粉配色 · 数据本地实时保存 · 每日内容自动轮换 · 无需服务器 · 无需联网

---

## 在线使用

直接打开就能用（手机浏览器也一样）：

```
https://<你的用户名>.github.io/yifan-workbench/
```

> 仓库推送后，在 **Settings → Pages** 里把 Source 选成 `main` / `/ (root)`，稍等一分钟即可访问。
> HTTPS + Service Worker + Manifest 三件套齐全，可以「添加到主屏幕」，效果跟原生 App 一样。

### 课表管理是两个重点功能

**1. 图片识别一键导入**
把超级课程表、教务系统之类的课表**截一张完整的网格图**上传 → 浏览器本地 OCR 识别 → 进入结果页逐条编辑（课程名 / 地点 / 星期 / 起止节次 / 删除）→ 确认后追加进课表。
识别全程在你手机本机完成，**图片不会上传到任何服务器**。

**2. 导出到系统日历（真闹钟）**
按「当前周」导出 `.ics` 文件 → 用手机自带日历打开 → 每节课变成一个**每周重复的日程事件**，并在**课前 10 分钟**（可调）带一个提醒。
也就是说：**到点会像闹钟一样响，锁屏也响，不用开着网页**。

## 安卓 APK

仓库根目录的 `一凡工作台.apk`（约 128 KB）是打包好的原生壳：

- 打开即用，**内置完整离线副本**，断网也能跑
- 有独立桌面图标和启动画面
- 导出 `.ics` / `.csv` / 备份 JSON 时，会**直接存到手机「下载」目录**（原生下载桥），不再是 WebView 里下不动
- 安装时若提示「未知来源」，允许一次即可；第一次打开需联网加载最新版，之后全部走本地缓存

> iPhone 没法装 APK，请用上面的网址「添加到主屏幕」，功能完全一致。

## 数据存在哪儿

**所有数据都在你自己的浏览器 / App 里**（`localStorage`，键名 `yifan_workbench_v2`）。

- 不会上传到任何服务器，这台会议室里没有后端
- **卸载 App 或清除浏览器数据 = 数据清空**，记得定期用「❓使用说明 → 导出备份 JSON」存一份
- 换手机：老设备导出 JSON → 新设备导入即可

## 本地运行

```bash
git clone https://github.com/<你的用户名>/yifan-workbench.git
cd yifan-workbench

# 任意静态服务器都行（必须通过 http(s) 打开，直接双击 index.html 会让 Service Worker 失效）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

手机要使用的话，`python3 -m http.server 8080` 后用电脑同 WiFi 的 IP 访问（`http://192.168.x.x:8080`）—— 但 HTTPS 才能装桌面和用 OCR，所以推荐直接用 GitHub Pages 网址。

## 技术说明

- **零依赖**：没有框架、没有构建步骤、没有后端，一个 HTML 一个 JS
- **离线优先**：Service Worker 页面走 network-first，静态资源走 stale-while-revalidate；缓存版本在 `sw.js` 顶部的 `CACHE` 常量里，改了内容记得 +1
- **每日轮换**：`seedOf()` 用 FNV-1a 把日期算成种子，`rnd()` 走 xorshift、`pick()` 走 Fisher-Yates——同一天刷新内容不变，隔天自动换
- **OCR**：运行时从 CDN 动态加载 tesseract.js（`chi_sim+eng`），中文识别包约 15 MB，**首次使用需要下载一会儿**，之后会缓存

## 想改点东西

| 想改什么 | 改哪里 |
| --- | --- |
| 题库 / 考点 / 素材 | `data.js` |
| 侧边栏加一个新模块 | `index.html` 里的 `VIEWS` 对象和侧栏 `<a data-v="...">` |
| App 名字 / 主题色 / 图标 | `manifest.webmanifest` + 替换 `icons/` |
| 缓存不更新 | `sw.js` 里 `const CACHE = "..."` 版本号 +1 |

> ⚠️ 改完 `index.html` 或 `data.js` 后，手机上如果还看得到旧内容，是 Service Worker 缓存的锅：去 「❓使用说明」里清一下，或者改一次 `CACHE` 版本号。
